Work Experience

Software Engineer - Teoresi SpA

Naples, Italy | January 2024 – August 2026

I worked as a Software Engineer at Teoresi SpA for two and a half years, where I had the opportunity to contribute to a variety of software engineering projects across different domains.

One of my main responsibilities was developing the back-end for a resource management tool. The system provides real-time visualization of weekly workload distribution across multiple projects, allowing users to efficiently monitor commitment hours. By optimizing SQL queries and back-end logic, I achieved HTTP response times under 2 seconds, even with large datasets.

Later, I was assigned to investigate and develop an initial DevOps pipeline. I set up a Harbor repository for artifact management and a Jenkins server to handle CI/CD on private infrastructure. The initial design was approved and evolved into the core automation pipeline for containerized builds, artifact versioning, and deployment, improving release reliability and consistency.

During the last six months at Teoresi SpA, I joined a team working with Hitachi Rail as an external consultant, contributing to the development of HMAX, a digital asset management and operational support platform.

My main focus was the Data Warehouse module, where I designed and developed ETL pipelines and data adapters to collect data from multiple sources, including trains, sensors, and logs, and ingest it into a centralized data hub for structured storage and long-term analytics.

One of my main tasks was rebuilding the SAP connector to ingest SAP tables into Databricks using Change Data Feed (CDF), allowing the system to process only incremental changes instead of the entire dataset. I also leveraged Apache Spark for parallel processing and performance optimizations, reducing the overall execution time by an average of 65%.
